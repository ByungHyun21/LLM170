# archive/ — 보존 아티팩트 (활성 코드 아님)

측정·판정 후 **비활성 보존**된 것(재개 후보 패치·1회성 구현 등)을 모은다.
- 각 항목의 상태(결론·전제·적용성)는 **그 파일 자체의 헤더**가 정본.
- 활성 스크립트는 `scripts/`, 내부 문서는 `docs/`(로컬 전용)로 간다.
- 이 폴더는 추적된다 — CMP 이전("코드만")에 함께 따라간다.
