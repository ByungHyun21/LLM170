# 개발기 — Ryzen AI Max+ 395 / Radeon 8060S (범용 모드 기준환경)

이 PC에서 범용(universal) 모드를 개발·검증. 검증된 지상 사실만 기록.

## 사양

- CPU: 16C/32T Zen5. Linux RAM 가용 30 GiB (총 128GB 중 96 GiB가 iGPU carve-out).
- GPU: **Radeon 8060S (gfx1151, RDNA3.5, 40 CU)** — UMA, amd-smi 98,304 MiB.
- OS: Ubuntu 24.04, 커널 6.17.

## 툴체인

- rustc/cargo **1.95.0** (`~/.cargo/bin`).
- **ROCm 7.2.2** 시스템 설치(`/opt/rocm-7.2.2`) + **ROCm 10.0.0** 타볼(`~/local_llm-runtimes/rocm-10.0.0/install`) 병렬.
- **CUDA 툴킷 없음** (nvcc/ptxas 부재) — CUDA 경로 검증은 배포기에서만 가능.
- Vulkan: Mesa RADV 26.1.7 (kisak PPA).

## 환경 변수 관례 (기존 `~/local_llm/models/*/run.sh` 패턴)

```bash
ROCM_ROOT=/opt/rocm-7.2.2   # 또는 ~/local_llm-runtimes/rocm-10.0.0/install
export LD_LIBRARY_PATH="$ROCM_ROOT/lib:..."
export ROCM_PATH="$ROCM_ROOT" HIP_PATH="$ROCM_ROOT"
```

## 백엔드별 실측 사실 (llama.cpp 기준, 2026-08)

- **Vulkan/RADV가 이 머신 최속**: HIP 대비 tg +11~29% (Mesa 26.1.7 + `fp16: dot2` 경로). cooperative matrix(VK_KHR_cooperative_matrix) 지원 확인.
- HIP(ROCm 7.2.2/10.0) 정상 동작.

## 알려진 HIP 특이사항 (엔진에 내재화할 것)

1. **CUB 부재** → top_k 등이 CPU 폴백 (자체 구현 필요).
2. **`hipStreamPerThread` 암시 동기화 없음** → 입력 H2D 쓰기와 그래프 읽기 레이스(실제 NaN 사고 사례 — `~/local_llm/models/qwen3.8-27b/ISSUES.md` §8). 백엔드 설계 시 스트림 동기화 명시 필수.
3. VMM은 `GGML_HIP_NO_VMM` 상당의 비활성이 안전.
4. 대용량 모델(96GiB 초과 요구)은 mmap 로드 필수 (dio OOM).

## 이 머신의 역할

- 범용 모드 개발·성능 기준선 (상대 비교/회귀 감지 전용 — CMP 절대 성능 예측 금지, 하드웨어 불일치).
- 96 GiB UMA → Flash-Next(111GB)를 제외한 전 테스트 캐바런트 수용.
